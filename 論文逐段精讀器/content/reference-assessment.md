修正搜尋標題混入網址、arXiv 出版資訊、編者及譯者資訊的問題，保留原始書目文字、ID、PDF 頁碼與座標；arXiv 依官方 `citation_arxiv_id` 與已印出的 DOI 一一核對。ERIC 的 Constructivism 文獻在修正標題後取得完整摘要，不再保留原先的缺漏提示。

所有可取得且身分相符的完整來源均送入本機繁中翻譯，與完整來源 SHA-256 及翻譯檢查點核對後嵌入。摘要卡沒有超連結或跳轉按鈕取代內容；來源網址只放在純文字折疊查核記錄。來源缺漏、權限／流量限制、逾時與身分衝突保持未完成，顯示目前查詢範圍與原因，不宣稱原文一定沒有摘要。

書目資料修正包括：期刊名稱不再誤刪正文、獨立數字的 DOI 續行不當成頁碼、`Article 558` 不附加進 DOI，以及 Crossref 主副標題合併。缺少 DOI 的搜尋須同時符合標題、第一作者與年份，且候選唯一；補齊的 DOI 保留原書目 DOI 與來源查核紀錄。Fui-Hoon Nah（2023）的原書目 DOI 與文章身分不符，已核對為 `10.1080/15228053.2023.2233814`，保留原始印刷值供核對。Bakeman（1997）、Barr（2011）因副標題漏配產生的警告已解決；Chang（2022）仍有標題／作者資料差異，未確認前不套用摘要。

執行 `npm run data:complete-reference-abstracts` 可續跑全部流程；結束碼 `2` 表示仍有未完成來源，不等於全部完成。只核對本機結果可加 `-- --offline`。資料庫遇到公開 API 限流或 504 逾時會保存成功快取與失敗紀錄，後續可續跑；不登入、解驗證或繞過限制。功能測試通過仍不代表內容通過人工校訂。封裝 skill 前須另行核對各來源摘要／翻譯的散佈授權，私人完整快取不直接打包。

## 證據與安全處理

- Crossref 只以印在該筆書目中的 DOI 查核，確認回傳 DOI 一致後，再比對標題；不根據 PDF 連結矩形或最長網址推定身分。
- 同筆書目印有多個獨立 DOI 時不自動選擇。頁首作者資訊與小寫姓氏前綴會在擷取時處理，防止跨筆合併。
- 4 筆標題比對警告：論文 02 的 Chang（2022）、03 的 Bakeman（1997）、05 的 Fui-Hoon Nah（2023）、06 的 Barr（2011）。這些可能來自書目錯誤、標題變體或解析問題，不直接判定作者引用錯誤，也不套用摘要。
- DOI `10.1504/ijmlo.2020.10026334` 的 Crossref 回傳身分不一致，查核保持未完成。成功快取不受影響，補查指令會以非零狀態回報。
- 115 筆可取得的摘要均已有中文整理。大多為從來源摘要自動選取完整句子後的本機摘譯，明確標示 AI 草稿，不保證涵蓋全部結果；不能替代完整摘要或全文閱讀。
- 摘要與「本文引用脈絡」分開呈現。一般引用保留所在段落的白話整理及原句；多篇合併引用不歸因給單一文獻。
- 圖 2 說明段中的 Vega、Huang 有特定引用角色整理，僅在正文確實含有共同依據的原句時套用。依據的出版社摘要為 [Vega](https://link.springer.com/article/10.1007/s10639-012-9242-8)、[Huang](https://www.sciencepublishinggroup.com/article/10.11648/j.sjedu.20160406.15)；另補查 [Bisra 後設分析](https://link.springer.com/article/10.1007/s10648-018-9434-x)。出版社補查文字同樣不標為人工校訂。
- 原文摘要只在介面提供最多 25 個英文詞的節錄；完整來源有外部連結。讀者筆記、閱讀進度與校編草稿仍留在本機。
