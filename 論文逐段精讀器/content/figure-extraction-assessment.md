# 八篇論文的圖表顯示可行性評估

評估日期：2026-09-16

## 結論

八篇 PDF 的圖、表與圖說都能以「PDF 區域高解析度裁切」正常顯示。但不能只依賴 PDF 內嵌圖片擷取：多個圖表由点陣圖、向量線條與 PDF 文字混合組成，表格更常完全是文字加向量線條。若只抽出內嵌圖片，會遺失標籤、線條、圖說或整張表格。

第二階段應以 PDF 裁切為必定的權威顯示，以原始內嵌圖片為可選的畫質優化。

## 已採用的圖表管線

1. 保留「段落 ↔ 圖表」關聯、PDF 頁碼、裁切座標與圖說文字。
2. 以 PDF.js 將指定區域以至少 2× device pixel ratio 繪製，這是所有圖表的穩定備援。
3. 若圖表是單一點陣圖物件，可額外擷取原始圖片；但必須與 PDF 裁切當對照檢查。
4. 表格第一版保留原始裁切。只有在表格結構經人工檢查後，才增加可存取的 HTML 表格，且不取代原圖。
5. 目前 123 個圖表項目已完成裁切與關聯；其中自動裁切失敗者已逐張以原始頁面人工重裁並記錄為 `manual-crop`。未來校編器仍可再加入視覺化座標調整功能。

## 第二階段驗收門檻

- 每張納入的圖表都必須有 PDF 頁碼與合法邊界座標。
- 裁切不得截斷圖說、軸標籤、圖例、表頭、註解或顯著性記號。
- 圖表不能只因關鍵詞命中就自動對讀者顯示；關聯必須經人工確認。
- 在桌面與行動尺寸都要檢查可讀性；行動版允許點擊放大。
- 若原始內嵌圖片與 PDF 頁面外觀不一致，以 PDF 裁切為準。
